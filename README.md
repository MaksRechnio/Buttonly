# Buttonly

A beautiful collection of 20 animated SwiftUI buttons with interactive tutorials that teach you how to build each one from scratch.

![Swift](https://img.shields.io/badge/Swift-5.0-orange) ![iOS](https://img.shields.io/badge/iOS-17+-blue) ![SwiftUI](https://img.shields.io/badge/SwiftUI-5-purple)

## What's Inside

**20 Unique Button Designs** — From Neon Glow and Glassmorphic to Cyber Glitch and Gravity Float, each button features custom animations, haptic feedback, and polished interactions.

**Step-by-Step Builder** — Tap "Build This Button" on any design to walk through an interactive tutorial. Each step adds a new layer (shape, color, animation) with a live preview updating in real-time.

**10 SwiftUI Lessons** — Learn the fundamentals of button styling, shadows, gradients, borders, animations, and more through guided tutorials.

**Copy-Ready Code** — Every code block has a one-tap copy button so you can grab snippets and use them in your own projects.

## Getting Started

1. Clone the repo
2. Open `Buttons App.xcodeproj` in Xcode 15+
3. Build and run on a simulator or device (iOS 17+)
